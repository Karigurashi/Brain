```
Stage 1: StockSelector       → 选票（流动性/市值过滤）

Stage 7: DailyBacktester     → 日级信号 → 即时进出场，Val 扫参 / Test 一次
```


## 二、为什么这样做：核心设计原则

### 原则 1：严格时序隔离 — 零未来信息

```
Train (60%)        Val (20%)        Test (20%)
|···············|········|········|
  ← 挖掘因子               ← 选参数    ← 一次评估
```

- 因子表达式**只用 t 时刻及以前的数据**
- 参数优化**只在 Val 上做**，Test 只跑一次
- 任何涉及未来数据的地方都是"事后验证"，不是"事前输入"

### 原则 2：IC 的"未来比对"不是未来函数

这是最容易混淆的点，需要精确区分：

```
正确做法（本系统）:
  factor[t] = f(close[t-19], ..., close[t])     ← 只用历史数据
  IC = Spearman( factor[t], (close[t+3]-close[t])/close[t] )
  ↑ 对比的双方时间戳不同：一个是已知的，一个是尚未发生的
  ↑ "未来比对"只是打分手段，不是因子输入

错误做法（未来函数）:
  factor[t] = f(close[t+3])                     ← 偷看了未来价格
  ↑ 回测好看，实盘必崩
```

**IC 的本质：用今天的因子值去猜明天的涨跌，事后算猜得准不准。**

### 原则 3：Spearman ≠ Pearson

| | Pearson IC | Spearman IC（本系统） |
|---|---|---|
| 衡量 | 线性关系 | 排序关系（单调性） |
| 公式 | Cov(X,Y) / (σ_x·σ_y) | Cov(Rank(X), Rank(Y)) / (σ_rankX·σ_rankY) |
| 假设 | 因子值越大 → 收益越大（线性） | 因子值排序越高 → 收益排序越高（单调） |
| 适用 | 动量类因子 | 均值回归类因子 |

偏度反转因子不是线性的——恐慌越深反弹越强，但不成正比。Spearman 恰好匹配这个特征。

### 原则 4：滚动分位信号 — 适应非平稳性

```
不用绝对因子值，而是滚动分位数:

signal[t] = (过去20天里，今天的因子值排第几) / 20

例如:
  因子值 = -1.38 → 20天内排位 13/20 = 0.65 → 信号>0.60 → 买入
  因子值 = -0.29 → 20天内排位 5/20  = 0.25 → 信号<0.35 → 卖出
```

这样做的好处：因子值的绝对水平会随着市场结构漂移，但**相对极端程度**的判别力更稳定。

### 原则 5：Val 扫参 / Test 一次

```
Val 阶段: entry ∈ {0.60, 0.65, 0.70}
         exit  ∈ {0.35, 0.40, 0.45}
         max_hold ∈ {3, 5, 7}
         stop_loss ∈ {-0.05, -0.07, -0.10}
         → 3×3×3×3 = 81 种组合，选 Val Sharpe 最高

Test 阶段: 只跑最优组合一次，不再调参
```

避免参数过拟合：在 Val 上充分搜索，但在 Test 上只做一次最终评估。

## 三、与行业 Top 实践的比对

| 维度 | 行业 Top (WorldQuant/Two Sigma) | FactorLab 现状 | 差距/改进 |
|------|-------------------------------|----------------|-----------|
| **因子发现** | GP + 深度强化学习 + 自动微分 | GP + 模板挖掘 | 接近，缺 RL 搜索 |
| **市场状态** | HMM / 宏观 Regime 模型 | K-Means 聚类 | K-Means 对时序结构不敏感，可升级 HMM |
| **IC 评估** | Spearman / Rank IC | Spearman (一致) | ✅ |
| **信号构建** | 截面标准化 + 行业中性化 | 滚动分位数（单票） | 单票模式天然无截面偏差 |
| **回测** | 事件驱动 / 分钟级 | 日线 OHLC | 日线对 T+1 市场足够 |
| **过拟合防御** | Purge/Embargo/组合交叉验证 | Train/Val/Test + IC 稳定性门控 | 可加 Purge 防止自相关泄露 |
| **风控** | VaR/CVaR/最大持仓集中度 | 止损 + 最大持仓天数 | 基础但有效 |
| **交易执行** | 算法交易/暗池路由 | 收盘价成交假设 | 实盘需考虑滑点 |

## 四、之前的问题与改进

### 问题 1：IC 概念混淆

- **现象**：不清楚 IC 的"未来比对"是否构成未来函数
- **根因**：Spearman IC 把 t 时刻因子和 t+h 时刻收益放在一起算，乍看像偷看答案
- **修正**：明确区分"因子输入"（只用历史数据）和"IC 打分"（事后验证预测力），两者时间戳不同

### 问题 2：因子方向判断

- **现象**：不确定 IC 的正负号对信号构建意味着什么
- **修正**：
  - IC > 0：因子值高 → 未来涨 → 信号直接使用分位数
  - IC < 0：因子值低 → 未来涨 → 信号翻转（1 - 分位数）
  - `build_rolling_signal()` 中 `if ic_direction < 0: rank = 1.0 - rank`

### 问题 3：回测信号与实际交易脱节

- **现象**：最初回测使用绝对因子值构建信号，IC 不稳定
- **修正**：改为滚动分位数信号，让极端值的判别力在非平稳市场中保持稳定

> **核心认知**：量化的本质不是找到"预测未来的公式"，而是找到**可证伪、可重复、跨时间稳定的统计规律**，并在严格时序隔离下验证。IC 的"未来比对"是检验手段，不是作弊工具。
